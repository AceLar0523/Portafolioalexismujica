Jawitas Mi Chulumani - Sistema de Gestión Integral y Asistencia Gerencial

Estado: En desarrollo Tiempo: 7 meses (en progreso)

Plataforma web empresarial para administración y automatización de sucursales, optimizando logística, inventarios y toma de decisiones mediante agentes autónomos coordinados.

CONTRIBUCIONES Y EXPERIENCIA

Organización: Jawitas "Mi Chulumani" (Proyecto de Grado para Ingeniería de Sistemas).

  • Arquitectura Multi-Agente: diseño de un grafo de ejecución asíncrono y orquestado con LangGraph.
  • Supervisión Conversacional: implementación de un agente conversacional supervisor que coordina agentes especialistas de Inventario, Sucursales y Finanzas, impulsado por Gemini API.
  • Procesamiento Inteligente: integración de RAG, ChromaDB, OCR y Speech-to-Text.
  • Visión de Documentos: integración de Google Cloud Vision API para extracción inteligente y análisis de documentos.
  • Infraestructura Descentralizada: implementación de mensajería asíncrona con RabbitMQ.
